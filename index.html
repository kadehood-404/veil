What is Veil?

Veil is a free, reversible redaction tool for developers. It finds API keys, tokens, passwords, emails, IP addresses and other sensitive data in logs, configs and code, and swaps each one for a consistent placeholder like {{EMAIL_1}}. After you get an answer from ChatGPT, Claude or a forum, paste it back and Veil restores your real values. Everything runs locally in your browser.

Redact secrets before pasting into ChatGPT or Claude

Debug with an AI assistant without handing it your AWS keys, GitHub tokens, database passwords or customer emails.

Sanitize logs for GitHub issues and forums

Share stack traces and server logs publicly with IPs, hostnames, credentials and usernames stripped out.

Reversible placeholders

The same secret always gets the same placeholder, so the AI's answer still makes sense, and you can restore the originals in one click.

What it detects

Private keys, JWTs, AWS, GitHub, Slack, Stripe, Google and OpenAI-style keys, bearer tokens, password and secret assignments, credentials in URLs, emails, IPv4 and IPv6, MAC addresses, credit cards (Luhn-checked), SSNs, home-directory usernames, plus your own custom terms.

Is my data safe?

Detection, redaction and restoration all happen in your browser. Nothing is uploaded and there is no server component. The mapping between placeholders and real values lives only in this tab's memory unless you choose to keep it for the session or export it. Pattern matching is not perfect, so always review the output before sharing.
